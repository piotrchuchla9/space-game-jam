**Goal:** Dodać lokalny radar (minimapę) w HUD pokazujący pozycję rakiety oraz znajdźki (gears, canisters, flames, shields) w jej okolicy.

**Architecture:** Nowy komponent `Minimap` w `src/game/ui/Minimap.ts`, tworzony przez `HUDScene`. `FlightScene` emituje zdarzenie `updateMinimap` z pozycją rakiety i snapshotem znajdźków w zasięgu (pobieranym z `ZoneManager`). HUD rysuje mini-ikony sprite'ów na półprzezroczystym tle.

**Tech Stack:** Phaser 4, TypeScript, Vite. Brak testów automatycznych — weryfikacja manualna w przeglądarce (`npm run dev`).

```ts
getMinimapItems(rocketX: number, rocketY: number, range: number): MinimapItem[] {
    const items: MinimapItem[] = [];
    const inRange = (e: SpawnedEntity) =>
        Math.abs(e.body.position.x - rocketX) <= range
        && Math.abs(e.body.position.y - rocketY) <= range;

    for (const g of this.gears) {
        if (inRange(g)) items.push({ x: g.body.position.x, y: g.body.position.y, type: 'gear' });
    }
    for (const c of this.canisters) {
        if (inRange(c)) items.push({ x: c.body.position.x, y: c.body.position.y, type: 'canister' });
    }
    for (const f of this.flames) {
        if (inRange(f)) items.push({ x: f.body.position.x, y: f.body.position.y, type: 'flame' });
    }
    for (const s of this.shields) {
        if (inRange(s)) items.push({ x: s.body.position.x, y: s.body.position.y, type: 'shield' });
    }
    return items;
}
```

### Task 2: Stworzyć komponent `Minimap`

**Files:**
- Create: `src/game/ui/Minimap.ts`

- [ ] **Step 1: Utworzyć plik `src/game/ui/Minimap.ts`**

```ts
import { Scene } from 'phaser';
import type { MinimapItem } from '../systems/ZoneManager';

export class Minimap {
    private scene: Scene;
    private centerX: number;
    private centerY: number;
    private size: number;
    private range: number;
    private scale: number;
    private rocketOffsetYRatio: number = 0.25; // rocket przesunięta o 25% w dół środka

    private bg: Phaser.GameObjects.Rectangle;
    private frame: Phaser.GameObjects.Rectangle;
    private markers: Phaser.GameObjects.Image[] = [];
    private rocketMarker: Phaser.GameObjects.Triangle;

    constructor(scene: Scene, x: number, y: number, size: number, range: number) {
        this.scene = scene;
        this.centerX = x;
        this.centerY = y;
        this.size = size;
        this.range = range;
        this.scale = size / (range * 2);

        this.bg = scene.add.rectangle(x, y, size, size, 0x000000, 0.55).setOrigin(0.5);
        this.frame = scene.add.rectangle(x, y, size, size).setOrigin(0.5).setStrokeStyle(2, 0xffcc00, 0.9);

        const rocketScreenY = y + size * this.rocketOffsetYRatio;
        this.rocketMarker = scene.add.triangle(x, rocketScreenY, 0, 6, -4, -4, 4, -4, 0xffffff).setOrigin(0.5);
    }

    update(rocketX: number, rocketY: number, items: MinimapItem[]) {
        for (const m of this.markers) m.destroy();
        this.markers.length = 0;

        const half = this.size / 2;
        const offsetPx = this.size * this.rocketOffsetYRatio;

        for (const item of items) {
            const dx = (item.x - rocketX) * this.scale;
            const dy = (item.y - rocketY) * this.scale;
            const sx = this.centerX + dx;
            const sy = this.centerY + dy + offsetPx;

            if (sx < this.centerX - half || sx > this.centerX + half) continue;
            if (sy < this.centerY - half || sy > this.centerY + half) continue;

            const marker = this.scene.add.image(sx, sy, item.type).setDisplaySize(10, 10);
            this.markers.push(marker);
        }
    }

    destroy() {
        for (const m of this.markers) m.destroy();
        this.markers.length = 0;
        this.bg.destroy();
        this.frame.destroy();
        this.rocketMarker.destroy();
    }
}
```
